# E 开工提案：async / await（v1）

三个定案（2026-10-14 与 Leo 议定）：

1. **跨 await 借用 v1 禁**——freeze 不得跨 `.await`。树侧词法可查
   （await 是 freeze 冲突点），NLL 不在关键路径上。状态结构体只装
   owned 值，Pin 体系整个绕开。放开是以后的语义升级。
2. **Poll 极简面**——无 waker：`fn poll(self: *mut Self) ->
   Poll<Self::Output>`。v1 的 `block_on` 自旋。真事件驱动 IO 是
   v1+ 的事；加 waker 参数是 additive（cerium 无生态锁死签名）。
3. **生成器不暴露**——`yield`/gen 块纯编译器内部，另想清楚再开。

## 语法与脱糖

```
async fn fetch(n: i32) -> i32 { ... }        // async fn，返回匿名 Future
let v = fetch(1).await;                       // 任意表达式位（MIR 上 rvalue 已物化）
```

- `async fn f(A) -> T` 脱糖为 `fn f(A) -> impl Future<Output = T>`
  ——**#192 的 Tyexist 机器直接复用**：存在返回类型 + checker 写回
  槽，槽里写编译器生成的状态机类型
- 调用 `f(a)` 只构造状态机（实参搬入字段），不执行
- `.await` 只在 async fn 内合法；async 块 / async 闭包 v1 不做

## 语义

- 状态机：每个挂起点一个状态，外加 start/done。字段 = 跨挂起活的
  局部（MIR liveness 在切块点算，b1 facts 已有雏形）——只含 owned
  （定案 1 保证了这一点）
- `.await` 展开：poll 一次，Ready(v) 继续，Pending 置标签返回
  Pending，恢复点从下一状态进
- **递归 await 拒绝**：async fn 直接/间接 await 自己 → 状态结构体
  含自身 → 尺寸无穷 → layout 层拒绝，报错点名
- 挂起中丢弃 future：状态机 owns 字段，标准 drop 行走
- panic 即 abort（无展开），挂起中的析构不跑——现有语义不变

## 借用规则（树侧）

`.await` 是 freeze 冲突点：每个活 freeze 在 await 处不得存活——
报错建议"先把要用的值拿出来"。与 move 位同款的检查位置，无新机器。

## std 面

```
enum Poll<T> { Ready(T), Pending }
trait Future { type Output; fn poll(self: *mut Self) -> Poll<Self::Output>; }
fn block_on<T, F: Future<Output = T>>(f: F) -> T   // 自旋 poll，文档写明
```

## 变换（MIR 上，F1–F3 之后）

- 输入：async fn 的真指令 MIR（rvalue 已物化，await 是 poll call +
  branch）
- 切块：Pending 边即状态边界
- 活性：每条切边的活局部并集 → 状态结构体字段
- 生成：匿名 struct（标签 + 字段）+ `Future::poll` 的 impl +
  原 fn 体改写为构造器——编译器生成的 decl，走现有 Sym/impl 机器

## 刀序与验收

- **F1** rvalue 词汇（Assign/Binop/Cast/Aggregate/Builtin）——
  async 无关地基，289 程序字节钉死
- **F2** 聚合/闭包/vtable/模式门控上 MIR（最厚）
- **F3** MIR 发射器、树发射器退役（re-clone wart 随之退役）
- **E1** 变换本体（切块/活性/状态机生成）
- **E2** std 面 + 测试矩阵：run（block_on 端到端、多挂起、状态机
  字段 drop、嵌套 async）、err（借用跨 await、await 在非 async fn、
  递归 await）
- **E3** specs/14-async.md 落笔（实现钉死语义后）

## 开放问题（少而实）

- `async fn` 的匿名类型在错误消息里怎么拼写（`impl Future<...>`
  够不够，还是要个可读名）
- `for await`（异步迭代）——v1 不做，记边界
- block_on 的自旋要不要加 yield 提示（编译器侧无成本，纯 std 实现
  细节，做到 E2 再定）
