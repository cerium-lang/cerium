## 语言 / 编译器

- [ ] **X1 static 符号无 ns 段（跨 ns 撞车）**
      `constsym` 的 mangle 是 `$static.<name>`，fn 的 mangle 带路径而
      static 不带——两个 ns 的同名 static 在汇编层撞车（`symbol
      'static.N' is already defined`）。std 侧暂用独特名绕过
      （arg_count / arg_table）。修法：constsym 补 ns 路径段，与 fn 的
      mangle 对齐。
- [ ] **X2 尾表达式与 `return` 的 coerce 不一致**
      尾表达式 u32 变量能 coerce 到 i32 返回（want 机制收变量）；显式
      `return` 同变量被拒（recoerce 只收字面量）。两条路该走同一条规则。
- [ ] **X3 类型位置的 pub 检查缺口**
      值位置两处已补（rexprpath1 的值路径、call 的 f 路径）；类型位置
      （`use` 之外的类型引用读 ns table）同样不问 pub，spec
      11-namespaces.md「private is the directory's own」两侧该一致。
- [ ] **X4 `&mut` 作用在已是 mut slot 的 place 上叠双层 Tymut**
      `[3]mut u32` 的元素本身是 mut slot，`&a[0]` 天然借出 `*mut u32`；
      `&mut a[0]` 则叠出 `*mut mut u32`。类型层应拒绝双层 Tymut，或
      `&mut` 对 mut slot 直接给 `*mut T`。
- [ ] **X5 const 聚合取址垃圾值疑点**
      const 聚合（数组/struct 字面量）取地址读到的值有垃圾值嫌疑，
      未定位到根因。需要最小复现 + emit 侧排查。

## std / 库

- [ ] **S1 fmt::Error 与 map_err**
      PR #96 review 留言（方案已有）：fmt::Error 等 map_err 一起动。
- [ ] **S2 Iterator for-in desugar**
      spec 10-iteration.md 的 desugar（`for PAT in c` →
      `IntoIterator::into_iter` + `Iterator::next` 循环）。`@slice` 落地
      后 spec 10 的示例已可真跑，desugar 是这条线的自然下一步；
      现状 body.c 只认 slice/array/?T 三种 for-in。
- [x] **S4 print 精度+进制（本轮落地）**
      精度：`write_fixed_prec`（点恒在、零补齐、carry 整数进位、窗口
      cap 15）+ `[]u8` fmt 里按 `w.prec` 截断——截断住在值的行而非
      write_str（specials 会丢名字、write_fixed_prec 自身段落会自截）；
      `Writer.prec` 由 pad 设/清，counting 遍同设（width 量的是截断后
      长度）。进制：`write_u64_b`（块 64 宽、小写字母）+
      `write_int`/`write_uint` 入口读 `Writer.base`，消费点在 builtin
      的整数五行——值的属性归值的行，float 的窗口是十进制自己的；
      负数 magnitude+符号；`{:>x}` 从拒绝（228 旧形状）变合法，228
      换 `{:>z}`。测试 232（精度行为+count）/233（空精度拒绝）/234
      （进制+歧义消解+count）。
- [x] **{N} 已裁决不做（语言层堵死）**
      const 索引穿 pack 的 peel 违反 08-reflection.md「const 参数 fn
      是编译期工具，运行时不可用」；pack 行类型异构不可运行时索引；
      std 无堆不能缓冲重排。若未来语言层允许运行时 fn 携 const 参数
      （值泛量），此裁决可重开。
