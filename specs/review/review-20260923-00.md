## A. 必修矛盾

- [x] **A1 `@field` 编译期字段名 vs 运行时 `f.name`**
      `08-reflection.md` 的 Field access 段要求名字编译期已知；
      `10-iteration.md` 的 Serialization 示例与 `12-macros.md` 的示例在运行时
      循环里传 `f.name`。
      结论：引入 `comptime for` —— 被迭代对象必须编译期已知，循环在编译期展开，
      循环变量随之成为编译期常量。
      已落地：`08-reflection.md`（Field access 段 + `comptime` 定义句）、
      `10-iteration.md`（新增 Comptime For 小节 + Serialization 示例）、
      `12-macros.md`（示例）。

- [x] **A2 方法调用隐式取地址 vs「没有隐式借用」**
      `05-traits.md` 的 Trait 段、`03-move.md` 的 Arguments 段声明无隐式借用；
      但 `p.len()`、`it.next()`、`self.iter.next()` 都在隐式取址。
      结论：方法调用是糖 —— 接收者按方法声明的 `self` 适配（`*Self`→`&x`，
      `*mut Self`→`&mut x`，按值则不取址）；`&mut` 仍要求 `mut` 槽位；
      「无隐式借用」收缩为只管实参。
      已落地：`05-traits.md` 该段改写。

- [x] **A3 切片字段可写性两种说法**
      `01-types.md` 的 Slice 段（由绑定的 `mut` 决定）vs 同文件 Mutability 段与
      示例（由字段 `mut` 决定）；`10-iteration.md` 的切片迭代器通过 `*mut Self`
      写 `self.ptr`/`self.len`，两种规则下都不成立。
      结论：统一到字段级 `mut`；切片的 `ptr`/`len` 天生是 `mut` 字段（推进视窗
      不写被借数据，与「`[]T` 元素不可写」不冲突）；整体赋值仍由绑定的 `mut` 决定。
      已落地：`01-types.md` Slice 段改写、`10-iteration.md` 的 `Enumerate` 字段补 `mut`。

- [x] **A4 `@take` 示例违反前提**
      `03-move.md` Take 段 `take(x) = @take(&x)` 应为 `&mut x`；
      同段示例里 `let a` 不是 `mut` 却取 `&mut a`。
      结论：`@take` 收 `*mut T`（与 `@field` 返回地址一致，不破坏「无隐式借用」）。
      已落地：`03-move.md`（`let mut a`、`@take(&mut x)`、`@take(&mut u.f)` 及说明）、
      `01-types.md`（Union 段补「`let mut u` ⇒ 可对字段取 `&mut`」）。

- [x] **A5 拥有式数组迭代 = 从索引位置移动**
      `10-iteration.md` 的 `IntoIterator for [N]T` 产出 `T`；
      `03-move.md` 的 Moving Out of a Place 禁止从位置移出。
      结论：`ArrayIter` 用 `@take` 逐元素取出；为此允许「移动到新槽位时提升可写性」
      （`[N]T` → `[N]mut T`），理由是新槽位无别名。
      已落地：`01-types.md` Mutability 段补例外、`10-iteration.md` 写出 `ArrayIter`。

- [x] **A6 `mut Self` vs「没有独立的 `mut T`」**
      `05-traits.md` Drop 段的 `fn drop(self: mut Self)`；
      `01-types.md` Mutability 段禁止独立 `mut T`。
      结论：写成 `mut self: Self` —— 参数是槽位，与「`mut` 标记紧随其后的槽位」一致；
      「不存在独立 `mut i32` 类型」原样成立。顺带纠正：所有权来自按值传参，不来自 `mut`。
      已落地：`05-traits.md`（两处签名 + 解释句）、`01-types.md`（补「参数槽位」）。

- [x] **A7 部分移动示例结论矛盾**
      `03-move.md` Moving Out of a Place 的 `Wrap` 示例：
      `let y = w.big` 被拒后，`let z = w` 不应再报「w 不可完整使用」。
      结论：`let z = w` 改为 ✅；并补一句「绑定要么完整要么已死」——
      这正是静态插入析构的前提。
      已落地：`03-move.md` 示例注释 + 新段落。

- [x] **A8 `#if` 是否统一为 `comptime if`**
      结论：采用。`comptime` 一个标记三个位置（参数 / `if` / `for`），
      `08-reflection.md` 给出表；普通 `if`/`for` 输入恰好编译期已知时也折叠，
      `comptime` 只是把它变成硬约束。`12-macros.md` 只做事实性改动
      （Three→Two、删 `#if` 行），立论与用词不动——宏的设计尚未定，措辞保持开放。
      已落地：`04-generics.md`、`08-reflection.md`、`10-iteration.md`、`12-macros.md`。

## B. 缺口

- [x] **B1 `Copy` 覆盖面不全** — `03-move.md` Copy 段未提切片、元组、`?T`。
      结论：补切片（`[]mut T` 也是）、元组、以及「枚举跟随载荷」——
      原句会让 `Option<File>` 成为 `Copy`，与 `Copy`/`Drop` 互斥冲突（double free）。
      已落地：`03-move.md` Copy 段改写。
- [x] **B2 特异性排序缺 `mut`** — `04-generics.md` 的形状模式表；
      依赖点 `10-iteration.md` 的切片与数组迭代器。
      结论：表里补 `*mut T`/`*T`、`[]mut T`/`[]T`、`*mut [N]T`/`*[N]T` 三行，
      并补一句「可写更具体，因为可写类型能用在不可写处，反之不行」。
      已落地：`04-generics.md`。
- [x] **B3 `EnumField` 无载荷类型** — `08-reflection.md` 的 `TypeInfo` 与 `EnumField`；
      无法描述 `Some(T)`。
      结论：`EnumField` 加 `type: ?type`（`None` = 无载荷，与 `Field.type` 对齐）；
      `Slice` 加 `optional: bool`（与 `Pointer` 对齐）。`type` 自身不加变体。
      已落地：`08-reflection.md`。
- [x] **B4 反射数据的编译期性质未声明** — 已由 A1 的 `comptime for` 覆盖。
- [x] **B5 无 builtin 总表** — `@if`/`@cast`/`@take`/`@print`/`@close` 未汇总。
      结论：`08-reflection.md` 新增 `## Builtins` 总表（十一个内置，按用途分组，
      标出定义章节），原 Queries 表降级为 `### Queries` 子节；
      `@print`/`@close` 改为 `std::io` 的普通函数。
      已落地：`08-reflection.md`、`05-traits.md`。
- [x] **B6 无字段的 struct 声明未引入** — `struct is_same<A, B>;`。
      结论：统一成 `struct is_same<A, B> {}` —— 不引入 `struct X;` 这第四种形式
      （`;` 在 C 里是前向声明，xyz 没有声明/定义分离；特化信息在参数模式里）。
      另补一句「struct 的类型参数不必出现在字段里」。
      已落地：`04-generics.md`、`05-traits.md`、`08-reflection.md`。
- [x] **B7 `09-match.md` 的 open items 过期** — 仍说 `return` 未定义。
      结论：删掉该条目，开头指路句改为「Loops and `return` come in
      `10-iteration.md`」。已落地：`09-match.md`。
- [x] **B8 `if` 是否为表达式** — `04-generics.md` 的 `#if` 出现在值位置。
      结论：是。「值是所取分支的值，两分支类型须一致」；无 `else` 时未取路径产出
      `()`，故只作语句用。已落地：`10-iteration.md` 新增 `## If` 节。
